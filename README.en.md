# Sawatari Shizuku Codex v2 Pets

Three unofficial, non-commercial Codex Desktop v2 pets inspired by Sawatari
Shizuku from *Bishoujo Mangekyou -Wasurenagusa to Eien no Shoujo-*.

| Folder | Edition |
| --- | --- |
| `shizuku` | Full-body expressive |
| `shizuku-pixel` | Pixel |
| `shizuku-q` | Super-deformed Q style |

All three pets include the standard Codex v2 animations and sixteen clockwise
look directions.

## Install

Download `shizuku-codex-pets-v1.0.0.zip` from Releases. Extract it and copy
the `shizuku`, `shizuku-pixel`, and `shizuku-q` folders into:

```text
%USERPROFILE%\.codex\pets\
```

If `CODEX_HOME` is set, use `%CODEX_HOME%\pets\` instead. Keep `pet.json` and
`spritesheet.webp` together inside each pet folder. Reopen the pet or restart
Codex Desktop after installing.
